**Summary:** `app/components/preview/EditorToolbar.js`'s ten formatting-toolbar controls keep their own 40px touch floor rather than adopting `app/theme/mobileSx.js`'s shared `TOUCH_TARGET_SX` -- a DELIBERATELY ACCEPTED exception to the collapse R-299 records, not an overlooked fifth copy.

- **WCAG's own floor is already cleared.** 40x40 satisfies SC 2.5.8 Target Size (Minimum, AA), which is 24x24; the 44px `MOBILE_TAP_MIN` this contract enforces is the stricter iOS HIG / SC 2.5.5 (AAA) figure, which `mobileSx.js`'s own header comment already documents as platform guidance rather than an AA conformance requirement. - **These are `size="small"` buttons, unlike every call site R-299 collapsed.** All four files R-299 folded onto `TOUCH_TARGET_SX` size their buttons at MUI's default (`medium`) size, whose natural height (36.5px, R-299's own arithmetic) already clears the old `sm: "36px"` floor -- the collapse was a no-op there. `EditorToolbar.js`'s buttons are `size="small"`, `variant="text"` (MUI's default): `Button/Button.js`'s `size:"small", variant:"text"` override is `padding: '4px 5px'` at `fontSize: pxToRem(13)`, and the button variant's line-height is `1.75` (unitless, so it applies to whatever font-size is active): `13 * 1.75 = 22.75px` line box, `22.75 + 4 + 4 = 30.75px` border box.
