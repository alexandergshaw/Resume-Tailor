## 2. Contradictions resolved (mechanism choices are mine; proofs named)

1. **M3 progress direction — SETTLED by orchestrator = RPC-merge.** The child-table alternative
   (arch §6) is not planned. Proof it is honored: the migration adds `merge_study_plan_progress`;
   the delta contract (§4) produces a **single-`itemId`** `seenDelta`; no `study_plan_progress`
   child table appears anywhere.

2. **Sub-chunk boundary (arch §11 vs this task).** Resolved in §0: migration + RPC + shape test are
   IN; store is OUT (SC-B-persist).

3. **`status` default vs `study_plans_ready_has_modules` (I found this; AC/arch did not flag it).**
   Mirroring `application_digests` literally would set `status default 'ready'`. But a `ready` row
   with an empty `plan` violates the `ready_has_modules` CHECK. **Decision: `status` has NO DEFAULT**
   (follow the `interview_prep_packs.status` precedent, `20260914000000:137-139`, "No default,
   deliberately: an insert that omits status must error"). `writeStudyPlan` (SC-B-persist) always
   supplies a status explicitly. **Proof:** the shape test asserts the status CHECK vocabulary and
   asserts no `default` token on the `status` column line.

4. **EvidenceSet citation element shape — deliberately LEFT OPEN (see §7).** `cached_research` stores
   SC-A's EvidenceSet. Arch §13 records that the per-citation element shape (`{url,title,...}`) is
   NOT yet enumerated and the SC-A seat must read `buildCitedDigest`/`extractCitationSources` before
   freezing it. I therefore **do not** normalize the inside of a citation here; `normalizePlan`/
   `cached_research` treat citation objects as pass-through. Resolving it now would hand SC-A a wrong
   guess it would inherit.

### 4.2 `lib/studyPlan/studyPlanSchema.js` (pure, no IO)

```
export const STUDY_PLAN_VERSION = 1;                 // bump = shape migration event

export const DEFAULT_KNOBS = Object.freeze({
  newReviewRatio: 0.5,                               // D-3, arch §5.3
  weakTopicIds: [],
  pace: Object.freeze({ daysUntil: 7 }),
  topicScope: Object.freeze({ excludedAreas: [] }),
});

// Fills every default, clamps newReviewRatio to [0,1], coerces weakTopicIds/
// excludedAreas to string arrays, coerces pace.daysUntil to a positive int.
// NEVER throws; a null/garbage input returns a clone of DEFAULT_KNOBS.
export function normalizeKnobs(input) -> knobs

// Content-derived, stable across rebuilds (NEVER an array index). Deterministic
// function of item content, e.g. a short stable hash of
// `${topicHint}\u0000${text}`. Equal content -> equal key, so resume (C5/D-4)
// survives a plan regen. Collisions within one plan are the generator's concern;
// this helper only guarantees determinism + content-derivation.
export function itemKey(item) -> string

// Normalizes a plan: modules[] -> topics[] -> items[], each item { id (from
// itemKey if absent), topicHint, text, kind: "new"|"review", citations: [{url}]
// pass-through (citation INTERNALS not frozen here -- see plan §2.4/§7),
// remediation?: boolean }. Plan-level provenance:
//   provenance: { research: "complete"|"partial", unsourcedTopicIds: string[] }
//   engine: string            // S6 -- which engine produced it
// NEVER throws; missing fields default to a well-formed empty-but-flagged shape.
export function normalizePlan(input) -> plan

// Progress shape (arch §5.2), NEVER throws:
//   { v: STUDY_PLAN_VERSION,
//     cursor: { moduleId, topicId, itemId },
//     seen: { [itemId]: { revealedAt, grade?, dueAt? } },
//     startedAt, updatedAt }
export function normalizeProgress(input) -> progress

// Completeness helpers for S6 consumers (used by SC-C/generation later).
export function isPartialPlan(plan) -> boolean          // provenance.research !== "complete"
export function unsourcedTopicIds(plan) -> string[]

// THE DELTA CONTRACT (M3). Pure. Produces the exact { cursor, seenDelta } pair
// writeStudyPlanProgress (SC-B-persist) will hand to the RPC. seenDelta carries
// EXACTLY ONE itemId key -- the one card just revealed/graded -- NEVER the whole
// seen map. This is the property that makes two devices non-clobbering.
export function buildProgressDelta({ moduleId, topicId, itemId, revealedAt, grade, dueAt })
  -> { cursor: { moduleId, topicId, itemId },
       seenDelta: { [itemId]: { revealedAt, grade?, dueAt? } } }

// Guard the store/route can assert before an RPC call: true iff delta.seenDelta
// has exactly one own key and its value matches the seen-entry shape.
export function isSingleItemSeenDelta(seenDelta) -> boolean
```

### 4.3 Migration DDL — `20261011000000_n157_study_plans.sql`

Table (mirrors `application_digests` structure; `status` vocabulary + `ready_has_modules` are the
study-plan specifics):

```sql
create table if not exists public.study_plans (
  application_id      uuid primary key references public.applications (id) on delete cascade,
  user_id             uuid not null references auth.users (id) on delete cascade,
  status              text not null,                 -- NO default (see plan §2.3)
  plan                jsonb not null default '{}'::jsonb,
  knobs               jsonb not null default '{}'::jsonb,
  progress            jsonb not null default '{}'::jsonb,
  cached_research     jsonb not null default '{}'::jsonb,
  posting_fingerprint text not null default '',
  researched_at       timestamptz,
  engine              text,
  created_at          timestamptz not null default now(),
  updated_at          timestamptz not null default now(),
  constraint study_plans_status_check
    check (status in ('ready', 'partial', 'unavailable')),
  -- CASE-guarded, mirroring interview_prep_packs_ready_is_complete
  -- (20260914000000:194-211): #> returns SQL NULL on a missing key, jsonb_typeof
  -- of that is NULL which fails = 'array' and falls to `else false`, so an
  -- ungarded jsonb_array_length can never be reached on a non-array.
  constraint study_plans_ready_has_modules
    check (
      status <> 'ready' or (
        case when jsonb_typeof(plan #> '{modules}') = 'array'
             then jsonb_array_length(plan #> '{modules}') > 0
             else false end
      )
    )
);

create index if not exists study_plans_user_idx on public.study_plans (user_id);

alter table public.study_plans enable row level security;
-- 4 owner-scoped policies, drop-if-exists then create, exactly as
-- application_digests_{select,insert,update,delete}_own (20260817000000:58-72):
--   select  using (auth.uid() = user_id)
--   insert  with check (auth.uid() = user_id)
--   update  using (auth.uid() = user_id) with check (auth.uid() = user_id)
--   delete  using (auth.uid() = user_id)
grant select, insert, update, delete on table public.study_plans to authenticated;
grant all on table public.study_plans to service_role;
```

Function (arch §6 verbatim target; SECURITY INVOKER, no `p_user_id`, `auth.uid()` in the WHERE):

```sql
create or replace function public.merge_study_plan_progress(
  p_application_id uuid, p_cursor jsonb, p_seen_delta jsonb
) returns boolean
language plpgsql
security invoker
as $$
declare v_rows integer;
begin
  update study_plans
     set progress = jsonb_set(
                      jsonb_set(coalesce(progress, '{}'::jsonb), '{cursor}', p_cursor, true),
                      '{seen}',
                      coalesce(progress -> 'seen', '{}'::jsonb) || coalesce(p_seen_delta, '{}'::jsonb),
                      true
                    ),
         updated_at = now()
   where application_id = p_application_id and user_id = auth.uid();
  get diagnostics v_rows = row_count;
  return v_rows > 0;
end;
$$;

grant execute on function public.merge_study_plan_progress(uuid, jsonb, jsonb) to authenticated;
```
