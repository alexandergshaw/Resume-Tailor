## What I could not verify / findings

- **AC-10 [ENV]:** live first-person phrasing and live no-fabrication compliance are owner-env, written
  `describe.skip` unless `GEMINI_API_KEY`. Never green in CI; AC-6 (bundled directive on the wire) is the
  offline proxy. A failed offline instrument here would be INVALID, not a pass.
- **FINDING — AC-8 canary claim is inaccurate.** The AC/design state "SYSTEM_PROMPT is referenced by
  route.js only." At this HEAD `lib/copilot/askPrompt.js` **also** references it. I did NOT encode the
  wrong exclusivity claim; the census uses SYSTEM_PROMPT only as a liveness canary (set must be non-empty
  and include route.js). Downstream seats should not re-assert "route.js only".
- **FINDING — my own instrument defect, caught and fixed this round.** The `NO_FABRICATION` regex first
  matched the pre-existing salary clause ("never invent a specific pay figure") in `SYSTEM_PROMPT`, which
  made the no-fab half a zero-power check (the no-fab-deleted mutant would have survived). Fixed by scoping
  the no-fab/fact-kind assertions to the **appended directive** (`on.slice(bare.length)`), isolated from
  the baseline salary clause. Mutant 1 confirms the fix bites.
- **jsdom limits (disclosed in-test):** the checkbox's Space/Enter default action is not executed in jsdom,
  so keyboard operability is proven by TYPE (a native `<input type=checkbox role=switch>`, not disabled on
  the AI engine) rather than by simulating a keypress. The pointer-toggle test drives the real control via
  `input.click()` and asserts the real store persists — true end-to-end reachability (standing rule 2).
- **SYSTEM_PROMPT not exported:** AC-4 OFF-identity is proven against a live no-flag baseline wire, not an
  imported constant — I did not force an export purely for a test (standing rule 6).
