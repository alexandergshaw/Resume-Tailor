# N95 — Fresh verification (round 1)

**Role:** fresh, read-only verifier of commit `4d2d5a7` (optimistic move + working indicators + announcements). No production files touched. All mutation was performed in an isolated scratchpad copy built from `git archive 4d2d5a7`, never in the working tree.

## Method

The working tree currently has an N97 implementer mid-edit on five files that overlap N95's surface (`DocumentPreviewMount.js`, `docx.js`, `page.js`, `useDocumentPreview.js`, `previewBlob.js`, plus new untracked N97 test files). Per the brief, verification is scoped to N95's **committed** surface at `4d2d5a7`, not the live working tree.

To get a clean, mutation-safe copy of exactly the committed state (not the live tree, which would have mixed in N97's uncommitted edits), I built the scratchpad copy with `git archive 4d2d5a7 | tar -x` into `<scratchpad>/hw-clean/hello-world`, then linked `node_modules` via an NTFS junction to the real `hello-world/node_modules` (no copy of node_modules). This is a stronger isolation than a plain file copy would have given, because a plain recursive copy of the working tree (which I built first, then discarded) would have silently carried N97's in-progress edits into the "clean" baseline. All mutant construction/kill/revert cycles below ran against this git-archive-derived copy using the local binary, `.\node_modules\.bin\vitest.cmd run --no-file-parallelism`, from PowerShell (Bash cannot reach node on this host).

Baseline confirmed on the clean copy before any mutation: **6 test files / 30 tests, all green** (`app/hooks/moveOptimistic.rc.test.js`, `app/hooks/moveFeedback.rc.test.js`, `app/components/preview/smoothFeedback.rc.test.js`, `app/components/companyResearchAcceptAnnounce.test.js`, `lib/acceptedFacts/moveOptimism.test.js`, `app/hooks/moveInsertedFact.rc.test.js`). After every mutant below, the file was reverted and a byte-level diff against `git show 4d2d5a7:<path>` (via `diff --strip-trailing-cr`, to neutralize a CRLF/LF artifact from the edit tool) confirmed exact restoration before the next mutant — no residual mutation carried forward.
