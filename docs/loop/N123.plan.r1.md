### Step 1 -- Split `DocumentReviewSection.js` into reusable parts; default export byte-identical
**Files:** `app/components/preview/DocumentReviewSection.js` only.
Add named exports in the SAME module (keeps `n103.census` 43-47/83-86 happy -- one file, no new primitive import):

- `export function useDocumentReview({ request, surface, announce, busy, covered, loadRealMaterialLines, onReviewed })` -> returns `{ run, running, shown, presentation, label, caption, unavailable, helperId, resultId, hasResult, offerDownload, canCollapse, resultHidden, setResultHidden, noun }`. Holds ALL current state (`entry`, `runningKey`, `resultHidden`, `inFlightRef`, `currentKeyRef`), the `useEffect` key tracking, `runWithInputs`, and `run()` **verbatim**. Every hook is called before any early return (preserves the Rules-of-Hooks shape the current early `if (!request)` return already respects: the hook runs the hooks, the parts render null when `request` is null).
- `export function ReviewControl({ hook, surface })` -> the `<Button>` (type/size/variant/`onClick=hook.run`/`aria-describedby=hook.helperId`/`aria-disabled`/`aria-busy`/`startIcon`) plus the describedby caption node (`id=hook.helperId`). Modal: visible caption text, as today. Chat: the caption node carries `hook.caption` (= `request.title`) but is rendered **visually hidden** via the imported `visuallyHidden` (design §2.3; keeps H3/T16 linkage, removes the B5 duplicate).
- `export function ReviewResultRegion({ hook, surface, regenerateReport, regenerateRow })` -> the collapse row (`canCollapse`), the `offerDownload` `ActivityLogButton` row, and the result `<Box id=hook.resultId hidden=... sx=RESULT_SX[surface]>` with `regenerateReport` + `<DocumentReviewResult>`, then `regenerateRow`. Identical markup to today.
- `export default function DocumentReviewSection(props)` -> `const hook = useDocumentReview(props)`; renders `<Box component="section" aria-label={\`Review of this ${hook.noun}\`} sx=ROOT_SX[surface]>` composing `<ReviewControl>` + `<ReviewResultRegion>` **in the current DOM order, byte-identical** for both `modal` and the still-default-consumed `chat` call. **Landable because:** the only consumer today (ChatPanel line 627 and DocumentPreviewMount) still calls the default export; DOM is unchanged. Green: all `DocumentReviewSection.*.test.js`, `toggle.test.js`, `n103.census`, `ChatPanel.review.test.js`, `ChatPanel.reviewAnnounce.test.js`.
