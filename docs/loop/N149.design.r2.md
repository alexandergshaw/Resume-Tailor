## 4. `namedEntityTokens` — pinned to the byte (F6)

New export in `lib/copilot/answerLocal.js`, beside `literallyMentioned`. The implementer has NO latitude below; the checker diffs against it.

### 4.1 The stopword set — exact contents

```js
// Capitalized words that are capitalized only because they open a sentence or
// are ordinary function words — never the name of a company, product or tool.
// A word is in here ONLY if admitting a fabricated instance of it is impossible
// (it is not a real entity name), so this set can never widen the hole.
const COMMON_CAPITALISED = new Set([
  "I", "A", "An", "The",
  "And", "But", "Or", "Nor", "So", "Yet", "For",
  "As", "At", "By", "In", "On", "Of", "To", "Up", "If",
  "Then", "Than", "That", "This", "These", "Those",
  "There", "Here", "When", "Where", "While", "Whereas",
  "After", "Before", "During", "Since", "Until", "Because",
  "Although", "Though", "However", "Also", "Therefore", "Thus",
  "My", "Our", "Your", "Their", "His", "Her", "Its",
  "We", "He", "She", "They", "It", "You", "Me", "Us", "Them",
  "Each", "Every", "Some", "Any", "All", "Both", "Either", "Neither",
  "Once", "Now", "Later", "First", "Second", "Third", "Next",
  "Finally", "Overall", "Instead", "Meanwhile", "Still",
  "Just", "Only", "Even", "Not", "No", "Yes",
  "With", "Without", "Within", "From", "Into", "Onto",
  "Over", "Under", "Through", "Across", "Between", "Among",
  "One", "Two", "Three", "Four", "Five",
]);
```

AC owns whether to add/remove members. The design constraint AC must preserve: **never add a token that is also a real product/company/tool name** (doing so lets a fabricated instance of that name through). Omitting a genuine function word is the safe direction (it only narrows depth, never lies).

### 4.2 The tokenizer and the three qualifying rules

```js
export function namedEntityTokens(text) {
  const tokens = String(text || "").split(/[^A-Za-z0-9'’]+/).filter(Boolean);
  const out = [];
  const seen = new Set();
  for (const t of tokens) {
    if (t === "I") continue;
    if (COMMON_CAPITALISED.has(t)) continue;
    const isEntity =
      /[A-Z]/.test(t.slice(1)) ||                                  // R1 internal/trailing caps: PostgreSQL, GitHub, OAuth, iOS, EC2
      (/^[A-Z0-9]+$/.test(t) && /[A-Z]/.test(t) && t.length >= 2) || // R2 all-caps acronym (digits allowed): AWS, SQL, CI, S3, H100, GPT4
      /^[A-Z][a-z]/.test(t);                                       // R3 initial-cap word: Rust, Python, Google, Agile, Stripe
    if (!isEntity) continue;
    const key = t.toLowerCase();
    if (seen.has(key)) continue;
    seen.add(key);
    out.push(t);
  }
  return out;
}
```

Total by construction: never throws; returns a (possibly empty) `string[]`.

### 4.3 Decisions the brief demanded a ruling on

- **Digit-bearing all-caps acronyms (S3, EC2, H100, GPT4, RDS, GCS): ADMITTED** via R2 (`^[A-Z0-9]+$` with at least one letter, length >= 2). A pure numeral run ("2043") has no letter and is NOT an entity — figures are step 5's job, not step 6's. This is the deliberate split so "2043 in the unit" cannot license a figure and an acronym cannot license a number.
- **`C++`, `C#`, `F#`, lone-letter language names (`C`, `R`), and mixed-case-with-embedded-digit tokens (`K8s`): KNOWINGLY SKIPPED.** The `+`/`#` characters are token delimiters, so `C++` tokenizes to `C`, a single capital that matches no rule; `K8s` (cap, digit, lowercase) matches none of R1/R2/R3. Admitting these cleanly would require special-casing two or three literals and widening the token charset, for a class the PROMPT already refuses. Stated as a residual (Section 9), not hidden. Most real infra names are all-caps (caught) or initial-cap (caught); this residual is narrow.
- **Sentence position is NOT used** (unlike `critiqueLocal.countProperNouns`, `critiqueLocal.js:176-186`, which skips each sentence's first word and matches only `/^[A-Z][a-z]+$/`). A safety gate must see a sentence-initial `Rust`. The new export's header must name `critiqueLocal.countProperNouns` and state why it is a distinct predicate (scoring vs safety), so the search-trap checker does not read it as a re-declaration. `countProperNouns` is left intact.

### 4.4 Residuals (flagged, not hidden)

- **False positive (narrows depth, never lies):** a conventionally-capitalized generic technique not in the unit (e.g. `Agile`, `Kanban`) is dropped. Acceptable; the stopword set is the only tuning surface and AC owns it.
- **False positive:** an all-caps ordinary word (`THE`, `AND`) would be flagged by R2; vanishingly rare in first-person past-work prose. Acceptable.
- **False negative (prompt-only):** a lowercase invented tool (`i used redis`), `C++`/`C#`, `K8s`. Refused by the prompt, out of mechanical scope.
- **Possessive tokens (`Google's`):** `literallyMentioned` builds a word-boundary regex around the whole token, so `Google's` requires `Google's` (not bare `Google`) in the unit. Edge case; narrows only.

## 7. The timeout race — ENFORCED, not commented (F5)

New PURE module `lib/copilot/expansionTimeouts.js` (no React, no node, no env read at top level; safe in both the browser and server bundles):

```js
// The client's abort budget for one expansion round trip. The SERVER's own
// budget must always be strictly smaller, so that when both fire it is the
// server's diagnosis ("that took too long to look up") that wins the race, not
// the browser's generic abort. That ordering is ENFORCED by the clamp below,
// not left to a comment an env value could silently violate.
export const EXPANSION_CLIENT_TIMEOUT_MS = 10000;
export const DEFAULT_EXPANSION_SERVER_TIMEOUT_MS = 8000;

export function clampExpansionServerTimeout(rawMs) {
  const ceiling = EXPANSION_CLIENT_TIMEOUT_MS - 1; // 9999: strictly below the client
  const n = Number.isFinite(rawMs) && rawMs > 0 ? rawMs : DEFAULT_EXPANSION_SERVER_TIMEOUT_MS;
  return Math.min(n, ceiling);
}
```

`lib/config/env.js` gains the N137-pattern getter (mirrors `getLlmSearchIntervalMinutes`, `env.js:78`):

```js
import { clampExpansionServerTimeout } from "@/lib/copilot/expansionTimeouts";
export function getExpansionTimeoutMs() {
  return clampExpansionServerTimeout(Number.parseInt(process.env.COPILOT_EXPANSION_TIMEOUT_MS, 10));
}
```

`expansionClient.js:21` replaces its `const CLIENT_TIMEOUT_MS = 6000;` with `import { EXPANSION_CLIENT_TIMEOUT_MS } from "@/lib/copilot/expansionTimeouts";` and uses it at `AbortSignal.timeout(EXPANSION_CLIENT_TIMEOUT_MS)` (`:52`).

`route.js` replaces `const MODEL_TIMEOUT_MS = 4000;` (`:64`) and its use (`:248`) with `AbortSignal.timeout(getExpansionTimeoutMs())`, importing `getExpansionTimeoutMs` from `@/lib/config/env` alongside `getServerEnv` (`:2`).

**Why this ENFORCES the invariant:** `clampExpansionServerTimeout` returns a value in `[1, 9999]` for every input (NaN/0/negative -> 8000; anything >= 10000 -> 9999). So `server_timeout < EXPANSION_CLIENT_TIMEOUT_MS` holds by construction regardless of what an owner sets `COPILOT_EXPANSION_TIMEOUT_MS` to. The r1 "surfaced-but-not-enforced" honest-limit disappears: inversion is now impossible, not merely documented.
