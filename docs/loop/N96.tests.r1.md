## Per-test controls (over-fire / under-fire discrimination)

- AC-1 discriminator: `{1.5,12}` and `{2,6}` readouts must DIFFER and not bleed each other's numbers — a
  constant-label readout fails.
- AC-1 null / partial: the safe direction (source phrase, never a fabricated number) is the passing one.
- AC-3: the DEFAULT and CUSTOM cases are both asserted, in both directions, over 5 spacing shapes.
- AC-2(i): a false peer (`aria-pressed="false"`) is required, not just the active `true` — a scan that
  only finds the active one is not discriminating; and the drawn (`variant`) state is asserted alongside.
- AC-4 canary: the reset must be inert when `spacing===null` — the control against an always-live reset.
- AC-6 negative: no `[role="progressbar"]`, no `spacing-pending`, no `aria-busy` — the control against a
  fabricated pending spinner.

## Explicit-value pinning (inherited-default trap, N36 lesson)

The readout is text, not a styled block, so it carries no inherited-margin risk of the N36 kind. The one
inherited-default surface this chunk could touch — the preview `<p>`/`<li>` inline styles — is pinned by
AC-4/AC-6: after a reset the `<p>` must return to its **source** `margin:0pt 0 0pt` and carry NO forced
`line-height:1`, and after a preset it must carry the explicit `12pt`. These assert the exact applied
value, not merely that an element exists.
