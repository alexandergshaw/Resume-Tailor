## 4. The counts — droppedRemovedAlsoAccepted and filter-order equivalence

**`droppedRemovedAlsoAccepted` is disjoint-vs-overlap correct, proven in one run, not two
separate tests** (stronger than independent tests would be, since it rules out a mutant that
conflates the two fields): `autoInsertNothingEligibleCounts.test.js`'s main case seeds four

`droppedRemoved`, or that never incremented it, would fail this exact assertion
(`autoInsertNothingEligibleCounts.test.js:209-213`). Ran isolated: 2 test files / 4 tests, all
passed.
