  commit** — `lib/document/docx.js:35-37` (export), called at `lib/document/docx.js:668` inside

  `90bdff6`, well before N89). **Why it was still classified an orphan pre-commit is a real mechanism,
  not a mistake:** `lib/sourceScan/exportGraph.js:342-422`'s reachability graph only counts an export as

  module imports this name," which was true before this commit (no test or production file imported
  it — it was only called locally within `docx.js`) and is no longer true now that three new rc test
  files do `import { docxFileFromBase64 } from "@/lib/document/docx.js"`.
- **Confirmed genuinely referenced by the shipped tests**: `grep -rn "docxFileFromBase64"

  build a real `.docx` `File` for `TEMPLATE_FILE`/`ENGINE_B64` fixtures).
  Move to `TEST_REFERENCED` is correct, not masking a real orphan.
- **Re-ran the sweep**, not just read it: `npx vitest run --no-file-parallelism
