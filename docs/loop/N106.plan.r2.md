### Step 1 — `lib/review/contract.js` (+ `contract.test.js`) — the vocabulary, validators, and coverage derivation
Files: **new** `lib/review/contract.js`, `lib/review/contract.test.js`.
Exports/contracts (full signatures):
- `CATEGORY` — frozen enum object, the 7 members: `missing-keyword, vague-unsupported, repetition, unverifiable-metric, employer-plausibility, consistency, unsupported-authority`.
- `ORIGIN` — frozen enum: `posting, real-material, draft`.
- `FLOOR_CATEGORIES` = `Set{missing-keyword, repetition, unverifiable-metric, vague-unsupported}` (4). `LLM_CATEGORIES` = `Set{employer-plausibility, consistency, unsupported-authority}` (3).
- `assertContainedFlag(flag, index) → boolean` — true iff: `flag.spanId` is a scalar string ∈ `index.draftSpanIds.get(flag.draftKind)`; and if `evidenceRef` present, `evidenceRef.spanId` ∈ the id-set named by `evidenceRef.origin` (posting⇒`index.postingIds`; real-material⇒`index.realMaterialIds`; draft⇒`index.draftSpanIds.get(evidenceRef.draftKind)`), AND `evidenceRef.draftKind` present IFF `origin==="draft"`. Returns false (never throws) on any miss → caller drops. **Applies identically to mechanical AND judge flags** (design §6; the F2 judge-side containment row below depends on this being the single validator).
- `assertWellFormed(result) → boolean` — the AC-15 universal post-condition minus `spanId` containment (which is `assertContainedFlag`): category ∈ CATEGORY; `evidenceRef.origin` ∈ ORIGIN; `draftKind` present ⟺ `origin==="draft"`; `unresolvedQualifications[].requirementId` ∈ posting ids; `coverage` present, `engineMode ∈ {full,mechanical-only}`, `evaluatedCategories ⊆ CATEGORY`, `complete` boolean, AND the honesty coupling `complete === isSuperset(evaluatedCategories, 7-enum)` AND `engineMode==="mechanical-only" ⟹ complete===false`.
- `computeCoverage({ seamResolved, reportedLlmCategories }) → { evaluatedCategories, engineMode, complete }` — EXACTLY design §5: `evaluatedCategories = sort( FLOOR ∪ (seamResolved ? reportedLlmCategories : ∅) )`; `engineMode = seamResolved ? "full" : "mechanical-only"`; `complete = isSuperset(set(evaluatedCategories), 7-enum)`. `complete` is assigned ONCE, here, via `isSuperset`; nothing else sets it. **`reportedLlmCategories` is ∅ when the judge was absent, threw/timed-out (seamResolved=false), OR resolved with a malformed/missing `evaluatedCategories` (F1 — the caller passes ∅, never a coercion to all-LLM).**
Green: `contract.test.js` drives the coverage truth-table — embedded no-seam ⇒ 4/mechanical-only/false; `seamResolved` + all-3-LLM ⇒ 7/full/true; `seamResolved` + `reportedLlmCategories=∅` ⇒ 4/**full**/false (the resolved-yet-incomplete arithmetic, at the `computeCoverage` unit level); honesty-coupling accept/reject — and the two validators (scalar-accept; union-id reject; synth-id reject; draftKind-iff-origin-draft both polarities).
