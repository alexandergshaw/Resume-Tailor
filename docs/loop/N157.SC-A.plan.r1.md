## 3. RESOLVED: the arch's OPEN item — the EvidenceSet citation shape

**Confirmed element shape of `application_digests.sources`** (`digestCitations.js:376-385`,
`buildCitedDigest`): each element is

```
{ url: string, title?: string, start?: number, end?: number }   // url already safeExternalHref-passed at write time
```

`url` is produced by `citationHref(uri)` (= `safeExternalHref`) at write time (`digestCitations.js:308,317`);
a source whose url that gate refused was **never stored** (`:309-315`). `title` is stored only if
`citationLabel.js` admits it; `start`/`end` are UTF-16 offsets for *placed* citations (dropped for
"also-searched" entries, `:382-385`).

**FROZEN EvidenceSet citation field:** `citations: Array<{ url: string }>` — `url` taken **verbatim** from
`sources[].url` (preserving `safeExternalHref`'s verbatim contract), `title`/`start`/`end` **excluded**.
Rationale: the generator consumes evidence as grounding context, not as a rendered footnote; the render
surface (SC-C `StudyEvidenceCitation`) re-derives host/label from the href itself (SEC-F2) and does not
need SC-A to carry a title. Minimal field = minimal drift.

**Redirect-host suppression applied in the adapter (S2 defence-in-depth), even though the digest column
is already href-safe,** so S2 holds if any future path reads `application_digests` directly:

```
for each s in sources:
  if s is not a plain object or typeof s.url !== "string": drop
  href = safeExternalHref(s.url)                    // lib/url/safeExternalHref.js:81
  if href === null: drop
  host = citationHost(href)                          // lib/tracking/citationHref.js:61
  if host !== null and servesGroundingRedirect(host, href): drop   // citationHref.js:86
  else keep { url: s.url }   // verbatim
dedupe by url, preserve first-seen order
```

`servesGroundingRedirect(host, href)` **requires `host` already lower-cased/www-stripped** — that is
exactly what `citationHost` returns (`citationHref.js:61-72`); passing a raw URL as `host` would make the
check misfire. This ordering is load-bearing and is a named 4b assertion.
