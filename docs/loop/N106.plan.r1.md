### Step 1 — `lib/review/contract.js` (+ `contract.test.js`) — the vocabulary, validators, and coverage derivation
Files: **new** `lib/review/contract.js`, `lib/review/contract.test.js`.
Exports/contracts (full signatures):
- `CATEGORY` — frozen enum object, the 7 members: `missing-keyword, vague-unsupported, repetition, unverifiable-metric, employer-plausibility, consistency, unsupported-authority`.
- `ORIGIN` — frozen enum: `posting, real-material, draft`.
- `FLOOR_CATEGORIES` = `Set{missing-keyword, repetition, unverifiable-metric, vague-unsupported}` (4). `LLM_CATEGORIES` = `Set{employer-plausibility, consistency, unsupported-authority}` (3).
- `assertContainedFlag(flag, index) → boolean` — true iff: `flag.spanId` is a scalar string ∈ `index.draftSpanIds.get(flag.draftKind)`; and if `evidenceRef` present, `evidenceRef.spanId` ∈ the id-set named by `evidenceRef.origin` (posting⇒`index.postingIds`; real-material⇒`index.realMaterialIds`; draft⇒`index.draftSpanIds.get(evidenceRef.draftKind)`), AND `evidenceRef.draftKind` present IFF `origin==="draft"`. Returns false (never throws) on any miss → caller drops.
- `assertWellFormed(result) → boolean` — the AC-15 universal post-condition minus `spanId` containment (which is `assertContainedFlag`): category ∈ CATEGORY; `evidenceRef.origin` ∈ ORIGIN; `draftKind` present ⟺ `origin==="draft"`; `unresolvedQualifications[].requirementId` ∈ posting ids; `coverage` present, `engineMode ∈ {full,mechanical-only}`, `evaluatedCategories ⊆ CATEGORY`, `complete` boolean, AND the honesty coupling `complete === isSuperset(evaluatedCategories, 7-enum)` AND `engineMode==="mechanical-only" ⟹ complete===false`.
- `computeCoverage({ seamResolved, reportedLlmCategories }) → { evaluatedCategories, engineMode, complete }` — EXACTLY design §5: `evaluatedCategories = sort( FLOOR ∪ (seamResolved ? reportedLlmCategories : ∅) )`; `engineMode = seamResolved ? "full" : "mechanical-only"`; `complete = isSuperset(set(evaluatedCategories), 7-enum)`. `complete` is assigned ONCE, here, via `isSuperset`; nothing else sets it.
Green: `contract.test.js` drives the coverage truth-table (embedded no-seam ⇒ 4/mechanical-only/false; `seamResolved` + all-3-LLM ⇒ 7/full/true; `seamResolved` + `reportedLlmCategories=∅` ⇒ 4/full/false; honesty-coupling accept/reject) and the two validators (scalar-accept; union-id reject; synth-id reject; draftKind-iff-origin-draft both polarities).

### Step 3 — `lib/review/mechanicalDetectors.js` (+ test) — the six deterministic detectors
Files: **new** `lib/review/mechanicalDetectors.js`, `mechanicalDetectors.test.js`. Imports: `CATEGORY` from `./contract.js`; `selectAuthorityReference` from `./referenceSelect.js`; `extractKeywords` from `../llm/engines/tailor-lite/keywords.js` (V3); `headerDateSpan` from `../resume/parseEmployment.js` (V4). Defines OWN consts `VAGUE_OPENERS` (reimplemented ~12-item lexicon, V2) and `NUMERIC_CLAIM_RE` (own quantified-claim pattern, shape per `RESULT_METRIC_RE`), and an OWN word-boundary helper (reimplemented from `containsTerm`, V5). **Imports nothing from `lib/resume/critique.js` or `lib/copilot/`; never imports `METRIC_RE`.**
Exported detectors (each returns `Flag[]`, never an object):
- `detectMissingKeyword(draft, posting) → Flag[]` — posting keyword (via `extractKeywords`) absent from draft spans (word-boundary, NOT `includes`) ⇒ `{category:"missing-keyword", draftKind, spanId: requirement.id?}`… **NOTE** the AC-4 flag sets `spanId`=the requirement and `evidenceRef.origin:"posting"`. Containment is enforced downstream by the chokepoint; the detector only reads input ids.
- `detectRepetition(draft) → Flag[]` — phrase/lemma repeated across spans in one draft ⇒ `{category:"repetition", draftKind, spanId: oneSpan, evidenceRef:{origin:"draft", draftKind, spanId: siblingSpan}}`.
- `detectUnverifiableMetric(draft) → Flag[]` — `NUMERIC_CLAIM_RE` claim with no baseline/unit/source ⇒ `{category:"unverifiable-metric", draftKind, spanId}`. Draft-INTERNAL; does NOT consult realMaterial. Runs identically on both draft kinds.
- `detectVagueUnsupported(draft) → Flag[]` — `VAGUE_OPENERS` opener + no concrete outcome ⇒ `{category:"vague-unsupported", draftKind, spanId}`.
- `detectConsistencySkeleton(drafts) → Flag[]` — cross-span/cross-draft date/title contradiction (via `headerDateSpan`) ⇒ `{category:"consistency", draftKind, spanId, evidenceRef:{origin:"draft", draftKind:<other>, spanId:<contradicting span there>}}`. First-slice: unambiguous date/title only.
- `detectAuthoritySkeleton(draft, realMaterial) → Flag[]` — uses `selectAuthorityReference`; authority-claim lexicon (own) + coherence-vs-reference; **AC-13(b) fail-closed branch**: user-material draft with `referenceSpans=[]` ⇒ flag every authority/support-requiring span `unsupported-authority` (no evidenceRef). Emits flags in `unsupported-authority` but — per the erratum — this category does NOT enter `evaluatedCategories`.
Green: per-detector positive + clean control; the **"Go"/"going" word-boundary near-miss** clean control (AC-4); baseline-present metric clean control on BOTH drafts (AC-6); grep-level checks (no `critique`/`copilot` import, no `METRIC_RE`, `VAGUE_OPENERS`/`NUMERIC_CLAIM_RE` are own consts).

### Step 4 — `lib/review/reviewDocuments.js` (+ test) — the core orchestrator (the public analyzer)
Files: **new** `lib/review/reviewDocuments.js`, `reviewDocuments.test.js`. Imports `contract`, `mechanicalDetectors`, `referenceSelect`. **Does NOT import `geminiJudge.js`, `fetch`, `fs`, `wantsEmbedded`, or read `process.env`/`Date`/`Math.random`.**
- `async reviewDocuments(input, options = {}) → Promise<ReviewResult>` — signatures per design §2 (input `{drafts, posting, realMaterial}`; `options.judge?`; result `{flags, unresolvedQualifications, coverage}`).
- Sequence: (1) build `index` once (`draftSpanIds: Map<kind,Set>`, `postingIds`, `realMaterialIds` — empty set when realMaterial null); (2) run the six detectors → `mechanicalFlags`; (3) compute `unresolvedQualifications` (AC-14 — genuine gap listed; draft-resolved excluded; realMaterial-present phrasing gap excluded → surfaces as missing-keyword); (4) build `referencePlan` + `judgeRequest` (attach per-draft `authorityReferenceSpans`/`referenceMode`); (5) **the injected-judge seam with F3 containment** — `if (options.judge)` try/await, `seamResolved=true` on resolve, `reportedCats = Array.isArray(r?.evaluatedCategories)?…:[]`, `judgeFlagsRaw = Array.isArray(r?.flags)?…:[]`; `catch ⇒ seamResolved=false`; (6) **F4 restriction** — drop any judge flag whose `category ∉ LLM_CATEGORIES`; (7) **single `emit()` chokepoint** — the ONLY writer to the output `flags` array; `emit(flag)` runs `assertContainedFlag(flag,index)` first and returns early (drops) on false — EVERY mechanical AND judge flag goes through it; no detector/merge pushes directly; (8) `reportedLlmCategories = set(reportedCats) ∩ LLM_CATEGORIES`; dedupe exact duplicates; **sort by the §8 total content key** `[draftKind, spanId, category, stableStringify(evidenceRef), message]` (never input order); (9) `coverage = computeCoverage({ seamResolved, reportedLlmCategories })`.
- `ReviewResult` own-keys EXACTLY `{flags, unresolvedQualifications, coverage}`.
Green (this is where most public-surface AC tests pass): AC-1 containment post-condition over every fixture + union/synth drop; AC-2 Fixture H Run A≡Run B + H′ + U; AC-3 floor-defect positive + breaking fixture + floor-clean negative + `complete:true` positive control (fixed fake judge all-3-LLM); AC-9 cross-draft; AC-11 repeat + shuffle; AC-12 fetch-spy zero-call + seam-map; AC-13 both cases; AC-14 R1/R2/R3; AC-15 schema+coupling sweep.
